# prd-writing

产品组 PRD 写作 Skill。全量版维护当前完整定义；每个大版本定稿后，增量版向开发说明相对上一已交付大版本的变化。两类 PRD 按需加载对应说明。

## 安装

从 [GitHub 仓库](https://github.com/LewisEverest30/prd-writing) 下载，将包含 `SKILL.md` 和 `references/` 的目录放入 Skill 安装位置。安装后的结构为：

```text
~/.agents/skills/prd-writing/
├── SKILL.md
└── references/
    ├── full-prd.md
    └── incremental-prd.md
```

如果下载的仓库目录不是 `prd-writing`，安装时将目录改为该名称。更新时重新下载并替换安装目录，随后开启新会话。

## 使用

提供目标飞书云文档链接，并说明要执行的任务及 PRD 类型（全量版或 vX 增量版）。起草与重构直接在提供的文档中完成，审阅默认在聊天中报告。

- **起草**：把这份文档中的初步想法和原型整理成全量版 PRD，直接在原文完成。文档链接为 `<飞书文档链接>`。
- **重构**：按本 Skill 重构这份全量版 PRD，保全原有业务定义与有效信息。文档链接为 `<飞书文档链接>`。
- **审阅**：检查这份全量版 PRD 是否符合本 Skill，在聊天中列出问题和修改建议。文档链接为 `<飞书文档链接>`。

需要同时修改时，明确要求“审阅并修正”。只处理局部内容时，指定章节或选区。Skill 按任务及 PRD 类型读取对应说明，具体执行规则见 [SKILL.md](SKILL.md)。规范优先关系及业务事实冲突按 [SKILL.md 的核心边界](SKILL.md#核心边界)与[依据与冲突](SKILL.md#依据与冲突)处理。

# prd-writing

产品组 PRD 写作 Skill，用于在飞书云文档中起草、重构和审阅 PRD，支持全量版与面向研发的增量版。

## 安装与更新

将 [仓库链接](https://github.com/LewisEverest30/prd-writing)交给 agent：

> 请从这个仓库安装或更新 prd-writing Skill，保留完整的 SKILL.md 和 references/，并确认客户端能发现它。

完成后建议新开会话。使用前需已配置飞书、Figma 工具并取得相应权限。

## 使用

告诉 agent 使用 `prd-writing`，提供目标飞书文档链接；有原型时附具体 Figma 链接。无需本地业务仓库。

- **起草**：将这份文档中的初步想法整理成全量版 PRD，直接在原文完成：`<飞书文档链接>`。
- **重构**：按 Skill 重构这份全量版 PRD，保全原有业务定义和有效信息：`<飞书文档链接>`。
- **审阅**：审阅这份全量版 PRD，在聊天中报告问题和建议，保持原文只读：`<飞书文档链接>`。

只处理局部时指定章节或选区；需要修改时明确说“审阅并修正”。增量版需提供目标文档、本轮已确认冻结的最终全量版与上一已交付大版本基线；首次交付则说明无前版及已确认范围。

具体写作与核验规则见 [SKILL.md](SKILL.md)。

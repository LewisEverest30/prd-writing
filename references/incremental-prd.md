# 增量版 PRD

按 SKILL.md 共用规则交付已定稿大版本的变化，版本冻结及交付边界见“需求基线”。

## 写前核对

- 确认最终全量版 `vX.Y` 定稿，取得上一已交付大版本最终全量版或可核验快照，不从现版猜旧行为；首次交付注明无前版及首次范围。
- 逐项比较已确认定义，定位新增、修改、移除及全量版精确位置。资料／设计冲突按共用规则裁定，不编造差异。

## 开头与正文

标题含本轮大版本 → 相关资料入口表 → 正文。资料表依共用规则，含本轮最终全量版、上一已交付大版本基线及相关 Figma 原型／UI；首次注明无前版。

增量版是稳定交付件，只标本轮大版本及对应全量基线，不设版本管理表、历史变更记录，不继续维护小版本。不要求封面，不套全量五章，正文仅两章：

1. **本次增量总览**：用导图、流程图或表格说明新增／修改／移除范围、受影响功能与协作方，让开发先抓全局。
2. **按全量版 PRD 分点说明细节变化**：按对应功能给出全量版精确位置，写清上一已交付大版本行为 → 本轮最终行为；必要的界面、规则、数据、状态、异常、恢复、依赖、配合、验收要求随对应变化展开。首次不假造旧行为；未变完整定义只链接，不复制或另造定义；动态任务、Bug、实际验收结果指向现行记录。

## 交付检查

在实际范围内执行 SKILL.md 共用核验，并检查：

- **依据**：标题大版本与全量基线对应，正文前资料表可到达本轮最终全量版及相关设计；有前版时可到达上一已交付大版本基线，首次注明无前版。
- **覆盖**：逐功能双向核对“发现的每项新增／修改／移除 → 正文说明”“正文每项变化 → 基线位置”。覆盖整个大版本，非本轮最后两小版之差；首次核对已确认范围与正文。缺完整基线／首次范围时，覆盖完整性标待验证并说明缺口。
- **内容与唯一性**：总览清楚，变化可定位，必要依赖与验收完整，未复制未变定义；无版本／历史表，同大版无并行第二份增量版。
- **成品**：图示主流程、关键分支、真实页面及来源符合共用规则，原生节点可编辑；实际表格、自动标题编号及间距通过共用检查。

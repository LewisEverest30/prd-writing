# 全量版 PRD

按 SKILL.md 共用规则及以下结构维护产品内部的当前完整定义。功能按需展开，不为填模板制造内容。

## 封面与开头

- **封面必须有**：优先生成契合主题、克制且有高级感的高清图，可参考飞书标准封面风格融入功能意象。生成图严格 `2000×400` 像素，检查清晰度、裁切；无法生成或不达标则用合适的飞书内置封面。封面只作视觉表达，不冒充真实 UI 或硬件规格。
- 实际设置为飞书文档封面资源并回读生效；本地图或正文插图不算。
- 顺序：封面 → 版本信息短表 → 相关资料入口表 → 正文。前置信息平铺，不设“第 0 章”。
- 版本表仅一行当前信息，固定五列：`当前版本｜状态｜审核人｜创建日期｜本版变化`。不用“项目｜内容｜项目｜内容”或“（既有编号）”等无用说明；未知字段待确认。
- “本版变化”表头内含可点击的“详细变更记录见文末”，定位文末记录，不另加历史列。表内一句话概括本版变化，完整历史留文末。资料表依共用规则。

## 正文五章

1. **全文概述**，保留三节：
   - **背景与设计动机**（1.1）：简述背景、问题、动机，已有分析引用出处。
   - **名词解释**（1.2）：表格解释必要术语，权威定义直接引用。
   - **全文总览**（1.3）：必须用原生可编辑思维导图概括全文主旨及结构，不以表格／清单代替；与第二章的使用流程区分。
2. **功能设计**：章首总览整体使用流程，优先流程图／时序图。不建议静态分类或思维导图替代流程，可补充范围、组成、关系；并列功能各画主线，不虚构先后依赖。再按功能点设二级节（2.1、2.2……），先简洁功能图、后结构化文字，详见下节。完整指业务流程覆盖，不是页面、按钮、字段穷举。
3. **非功能需求**：写实际要求、适用条件及验证方式，无据不定数值。
4. **埋点、分层等**：保留该章，无内容留空。上线前补齐所有功能埋点，口径未定不编造事件／指标。
5. **排期**：固定下表，无人工排期时留一行空白，由用户及同事填写确认；已有人工内容必须保全，agent 不自行填写、清空或改动。动态进展指向现行项目排期记录。

## 第二章图示与小节写法

适用于章首及各功能节，目标是简明扼要、干练精致；原生图示、按需截图及缺图处理依 SKILL.md。无需截图也须核对 Figma；选图优先现行 UI，无 UI 用原型，标明来源类型。已有入口直接用，无入口询问一次。

- **选型**：用户时序操作或数据流转必须有流程图／时序图；信息组织、展示可用导图表达层级，兼有操作／数据流时须搭配流程／时序图，可组合使用。
- **节点**：按业务动作组织，可合并不影响理解的连续操作；保留影响路径、结果的关键判断及异常出口。纯判断用判断形状，后台处理用简洁文字。配图依共用规则放节点框内，必要时加短说明。
- **必要大量截图**：同板分区，明确标“简洁流程图”“详细流程图”。前者用短文字呈现主线、关键分支、结果，可独立理解；后者在节点内配多张截图补操作细节及界面对照。两图路径、结果一致，不设固定节点／截图数量门槛，仅必要时使用。
- **关系**：流程图使用原生连接器，端点绑定正确上下步节点、卡片外边界或判断节点，不误连内部截图、标题、空白。依据已确认业务规则，保全必要分支和关系，状态示例须明确标识；时序图保持消息关系，导图保持层级语义。
- **布局**：阅读方向明确、间距紧凑、字号清晰，减少折返、交叉、无效空白。截图保持原比例、清晰度、协调尺寸及页面／状态名。拥挤先复核截图必要性，必要大量截图用双图，不持续扩大主图或缩至难读；文字、形状、截图、连线分别可编辑。
- **图后文字**：用短列表／表格说明目的、入口、核心行为及图中无法判断的必要字段、规则、异常、恢复、验收条件。不写长段或逐图复述，同一规则只定义一次。配图缺失不阻塞有据文字与功能图，仅对应配图待补。

### 图示验收

逐图回读云端原生节点并检查实际预览：

- 主线、关键分支、结果清楚，布局紧凑、连线易追踪；截图有解释价值、来源可追溯、位于对应节点框内且可辨。双图中简洁图可独立读，两图业务一致。
- 逐条核对流程图连接器源对象、目标对象、方向、条件及必要关系；布局调整后复查附着，各对象可分别编辑。
- 清理无用截图、重复说明和长规则；流程难追踪或截图不清须调整，未完成核验标待验证。

## 文末详细变更记录

正文后放不编号表：版本、日期、实质变化、对应位置／增量版入口。可列当前及此前版本，同版多项变化合一行，不逐字重复文首摘要。内部小版本变化在此留痕，已交付大版本详细差异链接对应增量版。

## 完稿检查

在实际范围内检查以下对象，并执行 SKILL.md 共用核验：

- **封面与开头**：封面资源已生效，主题、清晰度、裁切合适；生成图尺寸准确，生成不达标用合适内置封面。两张前置表顺序正确，版本表五列一行，历史链接可达文末；资料具体、可达，缺口可见。
- **章节**：概述三节完整，术语表及全文原生思维导图齐全；功能章首覆盖使用主线，未以静态分类替代流程；各节先图后文，操作／数据流配流程或时序图，必要规则、异常、恢复、验收完整且无重复定义；非功能要求有条件和验证方式。
- **图示**：全部正文图示原生对象可分别编辑；第二章逐图通过上述节点与预览验收。无需截图可通过，必要配图缺失标待补，未核验标待验证。
- **埋点与排期**：第4章存在，无内容为空；排期列序正确，无人工填写时一行空白，已有人工信息完整保留且 agent 未擅改。
- **记录与成品**：文末记录可达，版本及状态符合需求基线；同一事实无多处完整定义，实际表格、标题编号、间距及范围外资源保全符合共用检查。

若另有开发交付任务，先确认本轮最终小版本再读增量版说明；仅维护全量版不加载该说明。
